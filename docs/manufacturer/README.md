## Production boundary

The supplied 24 × 18 × 6 ArtiosCAD PDF is marked “ONLY FOR QUOTE NOT FOR PRODUCTION.” These SVGs and the PDF handoff are therefore reference assets, not a claim that production dieline placement is complete. The manufacturer must supply or approve the final production dieline, print areas, bleeds, safe zones, component dimensions, and finishing method.

The SVG wordmark uses live League Spartan text. Load League Spartan and convert all text to outlines before releasing artwork for production. Keep the original editable source as well as the outlined production copy.

## Color intent

- Gold source color: `#EFBF04`.
- Matte-black source color: `#28282B`.
- Suggested spot-color targets and process approximations appear in the PDF handoff. Final inks must be approved against a physical Pantone guide or manufacturer drawdown; screen and conversion values are not authoritative production color standards.
